# D2 Monument Archive Catalog Taxonomy

閲覧サイトの大分類は、DB都合ではなくゲーム内で探す人の認知に合わせる。

## 同列に扱う大分類

1. キャラクター
   - ハンター、ウォーロック、タイタン、サブクラス
   - クラス専用防具や装飾もここから参照できる

2. 装備
   - 武器、防具、ゴースト、船、スパロー、エンブレム、シーズンアーティファクト、クランバナー
   - 武器はさらに武器種、弾薬、属性、スロットで絞る

3. 外観/コレクション
   - 感情表現、フィニッシャー、シェーダー、武器装飾、防具装飾、ゴーストプロジェクション、トランスマット効果

4. 所持品/進行
   - クエスト、バウンティ、伝承、エングラム、パッケージ、消費アイテム、材料、通貨

5. 改造/パーク
   - 武器改造パーツ、防具改造パーツ、ゴースト改造パーツ、パーク、特性、内在効果、強化特性

6. 全データ
   - 分類横断の検索用。通常の閲覧起点ではなく、取りこぼし確認のための入口。

## TTKの扱い

TTKは武器、防具と同列の大分類ではない。PvPの体力+シールド基準、Sandboxバージョン、武器のダメージ/RPM/バースト条件に依存するため、各武器の詳細データとして保持する。

未検証のTTKは `pending` として表示し、`data/static/ttk/ttk_candidates.csv` に検証済み行が追加された時点で武器詳細へ反映する。
